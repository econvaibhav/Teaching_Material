2.3 Splitting Variables

There are multiple ways to split a variable in R. Now that we know what $ does, let us look at how to create new columns. To start of, let is create an empty column.

To create an empty column, we will use this command: Dataframe_name$Name_of_new_column <- NA. For example:

ESS_Subset$News_Split <- NA

Check the ESS_Subset dataframe now! You should have an extra column News_Split at the end of the dataframe with all NA Values.

We can also set to this to any value we would like, for example instead of NA, we can have all the cells take the value of 0.

ESS_Subset$News_Split <- 0

Question

What could be a use of first creating an empty column?

If we are using the if() statement in R to create columns, then any row which does not fill the criteria already has some logical value. It also helps with avoiding type conflicts.

In today’s class, we will look at three ways to split a column variable in R:

The ifelse() function is the quick way to split data. It can get quite messy in many cases. It works by evaluating a logical condition and returning one value if TRUE and another if FALSE. To handle multiple splits, you will have to “nest” the functions.

Tip!

In R, nesting an ifelse() simply means putting a second ifelse() statement inside the “else” (false) slot of the first one.

The standard syntax for a single ifelse() is: ifelse(condition, value_if_true, value_if_false)

To nest it, you replace value_if_false with a brand new ifelse(): ifelse(condition1, value1, ifelse(condition2, value2, value3))

How can be use this command to split one of our columns? Give it a try! Try splitting into 2 factors and 3 factors.

Using tidyverse is cleaner and easy to read. case_when() is the cleaner, more powerful version of ifelse(). It allows you to list multiple conditions sequentially without nesting!
